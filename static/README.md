# 99 Cell Roulette

A web-based roulette game with 99 cells where players can select 1-3 cells per bet.

## Features

- User registration with CAPTCHA
- Two-factor authentication (Google Authenticator)
- 99-cell roulette with 1% win chance
- Game hash verification system
- Bet history tracking

## Deployment on Render

1. Create a new Web Service on Render
2. Connect your GitHub repository
3. Select the `render.yaml` configuration
4. Deploy!

The app will be available at the provided Render URL.
